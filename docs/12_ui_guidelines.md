# UI Guidelines

## Theme

- Dark mode first
- Primary: Indigo / Purple
- Accent: Blue / Green

## Components

- Rounded cards (16px+)
- Soft shadows
- Minimal borders

## Typography

- Clear hierarchy
- Japanese text larger

## Animations

- Subtle transitions
- Card flip
- Progress animations

## UX Principles

- Keep it distraction-free
- Focus on content
- Avoid clutter
